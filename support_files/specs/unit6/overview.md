### Autonomous Pick-and-Place to Common Destination

* **Goal**: Achieve closed-loop autonomous pick-and-place manipulation from table landing coordinates to a dedicated SpindleTower destination. When an operator clicks a valid table point within ReachabilityBoundary, TeleopClient dispatches typed `PICK_AND_PLACE_TARGET` RobotCommand across Gateway to EdgeNode. Decoupled in-process `WorkcellState` registers the workpiece and calculates the next vacant SpindleTower slot ($z_k = k \times 0.02\text{m}$), emitting `WorkpieceSpawnedEvent`. EdgeNode's closed-form `AnalyticalInverseKinematics` solver computes joint trajectories for a deterministic 10-step pick-and-place sequence with downward tool orientation ($Z$-down), explicit Tool Center Point (TCP) offset ($0.108\text{m}$), and minimal angular displacement branch selection in $[-\pi, \pi]$. EdgeNode executes smooth joint trajectories at 30 Hz and toggles `palm_state` while streaming telemetry. In Three.js, `KinematicLinkAttachment` deterministically parents gear mesh to tool flange during grasp ($\le 15\text{mm}$) and deposits it onto SpindleTower upon arrival. SpindleTower accommodates up to 10 stacked gears with FIFO bottom-drop shift on overflow. Returning to `HOME` transitions `RobotState` back to `IDLE` and lifts `ClickLockout`.
* **Architecture**: Contract-first parallel development. Unit 6.0 locks down `PICK_AND_PLACE_TARGET` wire schemas and cross-language types. Units 6.1 (pure Python analytical UR5e IK solver & waypoint planner), 6.2 (EdgeNode event-driven `WorkcellState` & 30 Hz trajectory execution), 6.3 (Gateway stateless schema validation & routing), and 6.4 (TeleopClient SpindleTower 3D fixture, `KinematicLinkAttachment`, FIFO stacking, and click dispatch) execute against mocked interface seams. Unit 6.5 connects all services in an automated multi-service integration test suite.
* **TDD Assertion Matrix**:
  * **Test 1 (Domain / Schemas)**: Cross-language serialization tests asserting Python, Rust, and TypeScript validate `PICK_AND_PLACE_TARGET` payload (`pick_x`, `pick_y`, `pick_z`, optional `drop_x`, `drop_y`, `drop_z`).
  * **Test 2 (Kinematics / Pytest)**: Unit tests asserting closed-form analytical UR5e IK solver achieves $<1\text{mm}$ Cartesian accuracy against forward kinematics, enforces downward suction tool orientation, applies $0.108\text{m}$ TCP offset, rejects unreachable coordinates ($R < 0.20\text{m}$ or $R > 0.85\text{m}$), and selects minimal Euclidean angular displacement solution in $[-\pi, \pi]$.
  * **Test 3 (EdgeNode & WorkcellState / Pytest)**: Unit tests asserting `WorkcellState` emits `WorkpieceSpawnedEvent`, calculates incremental tower height ($z_k = k \times 0.02\text{m}$), EdgeNode executes 10-step sequence interpolating waypoints at 30 Hz with `palm_state` actuation, transitions `IDLE` $\to$ `PROCESSING` $\to$ `EXECUTING` $\to$ `IDLE`, aborts immediately on `EMERGENCY_STOP`, and resets on `CLEAR_WORKSPACE`.
  * **Test 4 (Gateway / Cargo Nextest)**: Unit tests asserting stateless schema validation passes valid `PICK_AND_PLACE_TARGET` frames, forwards to Zenoh `robot/{id}/command`, enforces 20 Hz rate limit, and rejects malformed payloads with structured `ErrorFrame` without terminating WebSocket connection.
  * **Test 5 (TeleopClient / Vitest)**: Component tests asserting SpindleTower mounts at $(0.40, -0.30, 0.0)$, `KinematicLinkAttachment` parents gear to `tool0` when grasped ($\le 15\text{mm}$) and unparents to tower at $z_k$ on release, FIFO bottom-drop shift operates when $N > 10$, table click dispatches `PICK_AND_PLACE_TARGET`, and "Clear Workspace" resets table and tower.
  * **Test 6 (Integration / Playwright)**: Multi-service end-to-end integration test asserting table click dispatches target across Gateway to EdgeNode, arm moves through 10-step sequence, grasps gear, stacks on SpindleTower, returns to `HOME`, restores `IDLE`, lifts `ClickLockout`, and executes second cycle within $< 50\text{ms}$ latency budget.
