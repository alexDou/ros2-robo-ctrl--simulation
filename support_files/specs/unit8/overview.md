### Conveyor Feed Flow (Flow B) — Hopper, Belt, Per-Gear Sorting

* **Goal**: Replace the click-to-place WorkcellTable workflow with the iter-2 Flow B showcase on a dedicated branch (`feat/conveyor-flow`, cut from `main` after the security branch merges; `main` keeps Flow A frozen, exactly one flow per branch, no runtime mode switch). The operator clicks **Fill**: the FeedHopper fills with a shuffled deck of 100 Gearwheels (exactly 10 defective in random colors + 30 `WHITE` / 30 `GREEN` / 30 `BLUE` sound). The operator clicks **Process**: the Conveyor runs `+Y → −Y` across the front of the arm, gears drop from the hopper one by one with random delay and random lateral position, each Batch holding a random 3..BeltCapacity gears (last may be smaller). The belt stops when the Batch lead gear reaches the downstream PickZone edge. TeleopClient then registers and dispatches gears **one at a time**: `SPAWN_OBJECT` carries coordinates plus the UI-assigned `color` + `intact`; sound gears get a `PICK_AND_PLACE_TARGET` to their SpindleTower and the UI waits for `IDLE` before the next gear; defective gears are committed straight to ScrapBin inventory with no arm motion and physically fall off the belt end on the next run. Batch done → arm HOME → belt restarts. Deck empty → final flush run → belt stops, Fill enabled, Process disabled. **Stop** is UI-only (belt freezes, current pick finishes, Process resumes). EmergencyStop is unchanged (→ `FAULT`) and FAULT, reload or reconnect resets everything. SpindleTowers auto-empty at 10 (stack fades ~1.5 s), the ScrapBin renders binary (green empty / red non-empty) and auto-empties at 100. Towers move to a rear stand at −X; the belt replaces the table at +X; the default camera moves to the robot's right side.
* **Architecture**: Contract-first parallel development. Unit 8.0 moves classification onto the spawn wire (required `color` + `intact` on `SpawnObjectPayload`), deletes the Gateway `QcClassifier`, and relocates tower/bin constants. Units 8.1 (Workcell semantics: defective-spawn direct scrap, tower auto-empty, reach tests), 8.2 (Three.js scene: conveyor, hopper, rear stand, Flow A removal, camera), and 8.3 (TeleopClient conveyor controller: deck, Fill/Process/Stop state machine, per-gear command loop) execute against mocked seams. Unit 8.4 connects everything in the seeded Cucumber E2E suite. Hopper/belt/batch state is TeleopClient-local only and never crosses the wire; WorkcellState stays the single authority for every registered gear (see ADR 0005).
* **TDD Assertion Matrix**:
  * **Test 1 (Domain / Schemas)**: Cross-language serialization tests asserting Python, Rust, and TypeScript require `color` (`WHITE`/`GREEN`/`BLUE`) + `intact` on `SPAWN_OBJECT`, reject missing/invalid values, reject any `SET_OPERATION_MODE`, and lock the relocated `WHITE/GREEN/BLUE_TOWER` rear-stand and `SCRAP_BIN` belt-exit constants.
  * **Test 2 (Workcell + IK / Pytest)**: Unit tests asserting a defective spawn commits directly to ScrapBin inventory with no pick pending, a sound spawn routes to its color tower, the 10th commit to a tower empties it (count → 0, siblings unaffected, no FIFO eviction), the bin empties at 100, `CLEAR_WORKSPACE` empties everything, and IK solves every PickZone corner (pick + approach height) and every rear-stand tower drop.
  * **Test 3 (Gateway / Cargo Nextest)**: Unit tests asserting spawn payloads pass `color` + `intact` through verbatim after schema validation (no enrichment, classifier module gone), and rate limiting / session exclusivity / telemetry handling unchanged.
  * **Test 4 (TeleopClient / Vitest)**: Deck generator yields exactly 10 defective + 30/30/30 sound with a seedable shuffle; Fill/Process/Stop button gating; batch size in 3..BeltCapacity; belt stops at PickZone edge; per-gear loop sends `SPAWN_OBJECT` then (sound only) `PICK_AND_PLACE_TARGET` and waits for `IDLE`; Stop freezes belt and resumes; defective gears fall off on restart; final flush; connect/FAULT resets local stores and sends `CLEAR_WORKSPACE`; tower fade on count reset; binary bin color; table/reticle/raycast code absent.
  * **Test 5 (Integration / Seeded Hermetic E2E)**: Mock-Gateway Cucumber suite with a seeded deck: Fill → Process full run to empty hopper, Stop/resume, EmergencyStop → reset, reload → reset, tower auto-empty at 10, bin green → red.
