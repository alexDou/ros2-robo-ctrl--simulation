### Interactive 3D Workcell & Click-to-Place Gear Ingestion

* **Goal**: Mount an interactive 3D table workcell in TeleopClient, implement raycast surface placement of gearwheels adhering to UR5e reachability limits ($0.35\text{m} \le R \le 0.75\text{m}$), enforce single-gear click lockout, dispatch `SPAWN_OBJECT` and `CLEAR_WORKSPACE` wire commands through Gateway to EdgeNode `WorkcellState`, and provide a "Clear Workspace" button in TeleopClient.
* **Architecture**: Contract-first parallel development. Unit 5.0 locks down `SPAWN_OBJECT` / `CLEAR_WORKSPACE` schemas and generated cross-language types. Units 5.1 (3D table workcell, raycaster, procedural gear mesh in Three.js), 5.2 (EdgeNode `WorkcellState` tracking & lockout enforcement), 5.3 (Gateway stateless schema validation), and 5.4 (TeleopClient "Clear Workspace" toolbar button) execute against mocked interface seams. Unit 5.5 connects all services in an automated multi-service integration test suite.
* **TDD Assertion Matrix**:
  * **Test 1 (Domain / Schemas)**: Cross-language serialization tests asserting Python, Rust, and TypeScript validate `SPAWN_OBJECT` (`{ "x": number, "y": number, "z": number, "object_type": "GEAR" }`) and `CLEAR_WORKSPACE` (`{}`).
  * **Test 2 (TeleopClient / Vitest)**: Component tests asserting table surface renders in Three.js at $Z = 0.0\text{m}$, ring reticle projector shows within $[0.35, 0.75]\text{m}$ and hides outside, valid click spawns gear mesh and locks out further clicks, and "Clear Workspace" button dispatches command and resets mesh/lockout.
  * **Test 3 (EdgeNode / Pytest)**: Unit tests asserting `WorkcellState` records active gear coordinates on `SPAWN_OBJECT`, rejects spawns during non-`IDLE` or when gear already present, and clears active gear on `CLEAR_WORKSPACE`.
  * **Test 4 (Gateway / Cargo Nextest)**: Unit tests asserting stateless schema validation passes valid `SPAWN_OBJECT` / `CLEAR_WORKSPACE` frames and rejects malformed payloads with structured `ErrorFrame`.
  * **Test 5 (Integration / Playwright)**: Multi-service integration test asserting table click in browser dispatches `SPAWN_OBJECT` across Gateway to EdgeNode, renders gear on table, locks out further clicks, and clicking "Clear Workspace" resets scene across all tiers.
